# 360 Vacuum for Home Assistant

> An open-source Home Assistant integration for 360 Robot Vacuums.

## 🎯 Project Goal

Create a complete Home Assistant integration for 360 robot vacuums using the official cloud protocol discovered through reverse engineering.

### Initial objectives

- Native Home Assistant integration
- HACS compatible
- Config Flow
- Complete vacuum entity
- Water level control
- Fan mode control
- Multi-floor support
- Room cleaning
- Zone cleaning
- Live map support (future)

## Supported models

The first target is:

- 360 X80-L
- 360 S8

The architecture will be designed to support additional models sharing the same protocol.
